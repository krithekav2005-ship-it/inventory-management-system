# Inventory Management System

A web-based Inventory Management System built using Python Flask, SQLite, HTML, and CSS.

This project helps manage products, stock, suppliers, and inventory transactions through a simple and user-friendly web interface.

## Features

- User Login and Logout
- Secure Password Hashing
- Dashboard
- Product Management
- Add Products
- Edit Products
- Delete Products
- Inventory Management
- Stock In
- Stock Out
- Stock Validation
- Stock History
- Supplier Management
- Low Stock Alerts
- Inventory Reports
- Responsive User Interface

## Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML5
- CSS3
- Jinja2
- Git
- GitHub
